1 Logging In

1

Website kholo

Browser mein agents-hub-fawn.vercel.app jao. Login page aa jayega.

2

Email aur Password dalo

Apna email aur password enter karo jo admin ne diya hai. Phir Sign In button dabao.

3

Dashboard pe pahunch jao ge

Login hone ke baad seedha dashboard khulega — yahan sab stats dikhein ge.

Tip: Password bhool gaye? Admin (Owner) se contact karo — woh Settings > Create Employee se naya password set kar sakte hain.

3 SEO Audit Kaise Run Karein

1

Sidebar mein "Run Audit" pe click karo

Ya Ctrl + K press karke "Run Audit" search karo.

2

Website URL dalo

Jis website ka SEO check karna hai uska URL dalo. Example: example.com — https:// khud lag jayega.

3

AI Provider choose karo (optional)

Default Gemini hai (fastest). GitHub, OpenRouter, ya Claude bhi use kar sakte ho. Agar ek fail ho jaye to doosra automatically try hota hai.

4

"Run All 5 Agents" ya ek agent select karo

Sab agents ek saath chalane ke liye button dabao. Ya neeche se koi specific agent card pe click karo.

5

Results dekhain

Score ring, Health Check, Findings, Keywords, aur Quick Wins tabs mein sab data milega.

Results ke baad kya kar sakte ho?

  • Re-audit — Same website dobara audit karo
  • Copy — Summary clipboard mein copy karo
  • JSON — Raw data download karo
  • Pin — Important finding pinboard mein save karo
  • Create Tasks — Findings se auto tasks ban jayein
Tip: Agar score 90+ aaye to confetti celebration hota hai! 🎉

4 Bulk URL Audit

Multiple websites ek saath audit karne ke liye:

1

"Bulk Mode" toggle on karo

URL input ke upar Bulk Mode button hai — ek click se activate ho jayega.

2

URLs paste karo — ek line pe ek URL

Maximum 20 URLs ek baar mein. Textarea mein paste karo.

3

Koi ek Agent card pe click karo

Woh agent sab URLs pe sequentially run hoga. Progress live dikhega — pending, running, done, error.

13 Settings & Security

Settings Page Sections

  • Profile — Name change karo
  • White-Label PDF — Company name, logo, accent color set karo (PDF reports mein use hoga)

15 FAQ / Common Problems

Q: Audit fail ho raha hai?

AI provider overloaded ho sakta hai. Doosra provider try karo (Gemini → GitHub → OpenRouter). System automatically fallback karta hai lekin kabhi sab busy hote hain — 1 minute wait karo.

Q: Score 0 aa raha hai?

Website ka URL check karo — https:// lagana zaroori hai. Agar site block karta hai crawling to score low aayega.

Q: PDF mein company name kaise change karun?

Settings > White-Label PDF section mein company name, logo URL, aur accent color set karo. Next PDF export mein use hoga.

Q: Dark/Light mode kaise change karun?

Topbar mein sun/moon icon pe click karo. Preference save hoti hai.

Q: Language kaise change karun?

Topbar mein globe icon pe click karo — English aur Urdu available hain.

Q: Email notifications nahi aa rahe?

Admin ko Vercel pe RESEND_API_KEY environment variable add karna hoga. Bina uske emails silently skip hote hain.
